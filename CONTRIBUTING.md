# Contributing to IssueBot

Start with a focused change and describe the user-visible behavior it improves. Keep product
setup in the README and contributor/operational detail in `docs/`.

- [Testing and feature acceptance](docs/testing.md): run a relevant regression group, add scenarios, and capture evidence before declaring a feature complete.
- [Operator workflow](docs/operator-workflow.md): understand scheduling and handoffs before changing orchestration.
- [Harness capabilities](docs/harness-capabilities.md): provider contracts and safety boundaries.

Include verification results and remaining limitations in your pull request. Do not use live
customer repositories or change running deployments as test fixtures.
