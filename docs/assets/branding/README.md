# IssueBot logo assets

Generated with the built-in image-generation tool on 2026-09-10. These transparent PNG assets are installed in the application and repository README.

- `issuebot-icon.png`: standalone ticket-shaped bot mark. A byte-identical copy at `src/main/resources/static/images/issuebot-icon.png` is displayed at 28px beside the accessible IssueBot sidebar title and used as the favicon.

The design combines IssueBot's cobalt-blue action color, an issue-ticket silhouette, and a checkmark eye. Keep proportions intact and leave clear space around the mark. The icon's white face is intentional, not background.

## Generation prompts

### Icon

Use case: logo-brand. Create one production-ready app icon for IssueBot, a developer tool that turns GitHub issues into reviewed, completed code changes. Square PNG with genuinely transparent background. A distinctive minimal cobalt-blue (#2563eb) robot head whose silhouette subtly resembles a rounded issue ticket: tiny centered short antenna, balanced clipped/rounded ticket corners, a simple white horizontal face inset. Inside the face use a dark cobalt small round left eye and a bold cobalt checkmark as the right eye, suggesting issue completion. Friendly but precise professional developer-tool branding, not a toy mascot. Flat vector-like geometry, strong silhouette, bold thick shapes, exquisite optical balance, no details that disappear at 24-32 pixels. Icon centered and fills about 85% of canvas, generous but not excessive transparent margins. Blue and white only. No words, no letters, no gradients, no glows, no shadows, no 3D, no border frame, no background texture, no mockup, no watermark. Deliver one isolated icon, not a sheet of variants.
