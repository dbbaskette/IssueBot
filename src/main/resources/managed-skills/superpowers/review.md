# Independent code review brief

Provide requirements, exact base/head or diff, changed files, and available test evidence.
Review read-only for spec compliance, correctness, security, regressions, and meaningful tests.
Inspect enough surrounding code to establish consequences; a diff is not always sufficient.
Do not assume the implementer’s narrative proves correctness. Reuse applicable test evidence
and use focused safe checks only for concrete uncertainty. Report limitations and material
findings with file/line evidence. Classify diagnostics by impact, not merely their presence.
No edits, posting, approval, merge, or recursive review delegation are authorized by this brief.

Return spec compliance, severity-ranked findings, and readiness with unresolved gaps.
