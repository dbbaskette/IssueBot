Quick start

Next steps

  1. Go to Repositories and add a GitHub repository to watch.
  2. On your GitHub repo, add the label agent-ready to an issue you want IssueBot to work on.
  3. IssueBot detects the issue while processing is enabled. Your repository workflow determines when work starts and which stages require approval.
  4. Monitor progress on the Dashboard.
Optional: example configuration

IssueBot looks for a config file at ~/.issuebot/config.yml. Choose your coding harness, models, and reasoning in Settings. Below is an example of the other configuration values: 

issuebot:
  poll-interval-seconds: 60
  max-concurrent-issues: 3
  work-directory: ${user.home}/.issuebot/repos
  github:
    token: ${GITHUB_TOKEN}
  notifications:
    desktop: true
    dashboard: true
  repositories:
    - owner: your-org
      name: your-repo
      branch: main
      mode: autonomous
      max-iterations: 5
      max-review-iterations: 2
      ci-enabled: true
      ci-timeout-minutes: 15
      security-review-enabled: false
      auto-merge: false
